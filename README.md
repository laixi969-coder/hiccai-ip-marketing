# hiccai-ip-marketing

一套**营销与个人品牌方法论** skill，来自一位长期从业的广告人 / 营销策划公司经营者。

用于做个人 IP / 个人品牌 / 起号、写广告语与起名、做借势与事件营销、消费者洞察与定价，以及"把自己从被分配者变成设计者"的商业模式设计。

本 skill 是**方法论 + 批判边界双轨交付**：每条能力都附带适用边界与失效条件。只读方法不读边界，等于照搬话术。

> 旧方法库保留匿名化整理稿；新增来源索引保留用户提供的书名、文件名与视频 ID 以便回查。整理稿不保证逐字还原，作者观点不等于效果已验证。

## 使用

将整个仓库目录安装到所用工具的 skills 目录。例如 WorkBuddy / Claude Code：


## 使用与许可

- 文中数字类断言（客户年限、收益、曝光量）**全部为当事人自述，未经核实**，不可用于任何定量结论。
- 旧方法库的匿名化引文为整理稿，不保证逐字准确；来源索引保留必要的检索标识。
- 本仓库的整理部分沿用 MIT 标记，不涵盖任何第三方原始表达与品牌资产。
- 整理后的方法论**不代表任何当事人观点**，也不构成对任何具体标的、平台或商业动作的建议。
- 素材存在同音字转写误差，已知错误表见 `references/CRITIQUE.md` 第 5.1 节。

普通任务从 SKILL.md 路由到所需模块；涉及对外引用时，再读 SOURCES 和 CRITIQUE 第四章「引用纪律」。
