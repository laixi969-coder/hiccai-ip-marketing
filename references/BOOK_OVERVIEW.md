## 二、结构：他到底在讲什么

### 骨架（三层）

```
第 1 层 · 时代判断  —— 为什么"做主角"是必答题而不是选择题
   ├─ 传统媒体（央视/代言人）失效，媒介即广告的时代结束
   ├─ 流媒体三大特征：反逻辑 / 反事实 / 反精英
   └─ 结论：不出现在屏幕上 = 等于 0；"当主角都是被逼的"

第 2 层 · 个人品牌 —— 如何把自己变成一个可被记住、可被交易的符号
   ├─ 核心命题：故事没人看，事故人人赞
   ├─ 七种武器：脸 / 声音 / 名号 / 主张点 / 孤独 / 同情点 / 重复
   ├─ 重构素材观：别对标别人，向内求，讲自己的"事故"
   └─ 复利机制：日拱一卒 + 利他 + 露脸 → 品牌复利

第 3 层 · 商业变现 —— 从被分配者到设计者
   ├─ 盈利游戏：做利润的设计者，不做被分配者
   ├─ 消费者洞察分层：月薪3000 / 月薪30000 / 年入千万大中产
   ├─ 十把镰刀：中国消费者十种可被设计的心理缺口
   └─ 好名字 / 熟人经济 / 其公司式高客单长约
```

### 七种武器（最常被他自己复述的框架）

| # | 武器 | 他的论证逻辑 |
|---|---|---|
| 1 | **脸** | 基因层面：森林里出现人脸一定被看见；刷脸是传播效率最高的识别方式；不露脸 = 无法变现 |
| 2 | **声音** | 耳朵是"眼睛的双倍份"；默片时代已结束；AI 时代靠语音交互；**绝不用机器人配音** |
| 3 | **名号** | 大脑懒惰，只记得住两个字（列宁 ≠ 弗拉基米尔·伊里奇）；"用真名他花两个亿都红不了" |
| 4 | **主张点** | 算法靠筛选取胜 → 观点越尖锐越能筛出喜欢你的人；**中正平和不会讨人喜欢**；要有道德制高点 |
| 5 | **孤独** | 做主角必然孤独：认知上"拉黑父母"→"拉黑朋友"→"拉黑过去"（不是决裂，是认知隔离） |
| 6 | **同情点** | 豪斯医生（残疾）、蝙蝠侠（父母双亡）、某知名创业者（还债）——缺陷换取同情与亲近 |
| 7 | **重复** | 印象曲线：看 1 次忘记 / 7 次有印象 / 30 次终生记住；他日均 100 万曝光、年总量 4 亿 |

### 十把镰刀（中国消费者十种可设计心理）

抬杠型 / 不安全感 / 好大喜功 / 忧国忧民 / 乡土情结 / 同情心 / 没苦硬吃 / 扎堆从众 / 喜新厌旧 / 留后路

> 每把镰刀他都给了"解决方案"：制造开放性话题、兜底式服务、突出大权高级感、绑定家国情怀、挖掘地域情感、消费与公益绑定、自虐式产品、稀缺感与从众、定期推新、灵活消费选项。

### 消费洞察分层

- **月薪 3000**：抠门经济学 —— "不是不花钱，是你没挠到痒处"；如何稀释缺钱的痛苦
- **月薪 30000**：伪精致、性价比焦虑、时间焦虑、买身份标签、圈层认同、自我感动式消费；"资本设计下的提线木偶"
- **年入千万大中产**：消费行为剖析

### 盈利游戏（他自称"毕生功力"）

- 两种人：**被游戏玩 vs 设计游戏**；**被分配利润 vs 设计利润**
- 中本聪作为原型：不加入任何现有牌桌，直接重新开一局（发行/共识/流通/稀缺四机制）
- 五条利他思维：① 解决痛苦越大利润越大 ② 让人越省力越收钱 ③ 给别人希望 ④ 成就别人 ⑤ 降低社会成本
- 五步落地：封装可复制产品 → 锁定一类人群一个痛点 → 设计自动运转流程 → 搭建分配机制 → 升级规则而非拼命干活
- 他的自证案例：个人账号（版税+广告）、其公司（某招聘平台10年/某科技公司8年/某游戏公司5年/某食品品牌3年）、IP+品牌+供应链三方整合

## 三、解释：他的底层方法论内核

**1. 传播学内核 = 记忆工程，不是内容工程**
他不谈"内容质量"，只谈"被记住"。七种武器里 6 个都是记忆抓取器，第 7 个（重复）是记忆固化器。

**2. 素材观 = 反对标**
"上海不能抄北京" —— 对标是个人 IP 里最糟糕的事。素材只能向内求（自己的事故），因为"你看得见的别人，也是别人对标来的"。

**3. 广告人的方法论平移**
传统广告链路：制造焦虑 → 寻找洞察 → 写文案 → 视觉锤 / 文字钉。
他的判断：短视频时代这一套底层人性"一模一样"，所以"传统广告人做 IP 是最简单的，没有任何挑战"。

**4. 反"文科新人"焦虑**
"中国五千年文科没有新知识，只有新观点、新角度"。文案不需要创新知识，需要换语言、换风格、换角度。

**5. 反"团队崇拜"**
"团队越大越干不动"。老板必须自己管两件事：产品、营销（营销比产品更重要）。他引用的比例：5000 美金做产品 / 25000 美金做营销。

**6. 反"学术化"**
"可以搞学说，不能搞邪教"；"思想不是写给聪明人看的，是给普通人解苦解闷解迷惑的工具"；要抓**跨朝代跨阶层跨年代的集体痛苦**，"临时的小烦恼不配做学术根基"。

## 四、批判：需要打问号的地方

| 问题 | 说明 |
|---|---|
| **大量断言无证据、强因果** | 多为"某粉丝照做后业务翻杯"式单一案例举证，无对照、无数据源 |
| **幸存者偏差** | 他的方法能否复制，取决于他本人的 20 年广告人积累 + 早期流量红利；他自述 2017 年入场 |
| **"设计游戏"话术的伦理灰区** | 十把镰刀本质是"如何利用人性弱点卖货"；他虽反复补一句"不要干坏事"，但方法论本身是单向利用 |
| **自证案例不可验证** | 其公司客户名单、账号收益均为自述 |
| **时代判断可能过时** | "流媒体反精英/流量还便宜"的论断基于 2023-2024 语境，2026 年平台格局与流量成本已变 |
| **认知隔离论** | "拉黑父母/朋友"作为成功必修课，是强观点而非普适规律，易被误读为鼓吹决裂 |
| **教学化身的利益冲突** | 他卖书、卖课程、接高客单咨询——"人人可做 IP"的叙事本身对他有利 |

## 五、应用：这份语料能变成什么

### 面向老板（蔡文斌）的可用性判断

**直接可用**：
- 七种武器 → 做个人 IP / 个人品牌的自检清单（尤其"脸/声音/名号/主张点/重复"可当天执行）
- 微信指数检验法（<1万不合格）→ 可量化的影响力仪表盘
- 受众分层洞察 → 卖东西前的"挠痒处"定位法
- 盈利游戏五步 → 从"出卖时间"转向"设计可复制价值"的路径

**需警惕**：
- 他的语境是**营销服务商/大客户生意**（高客单、长约、B端），与老板的 A 股投资场景无直接映射
- "十把镰刀"是进攻性话术，用于学习"识别别人怎么设计他"更有价值，而非照搬去设计别人

### 建议编译为一个 skill（single 模式）

入口技能「hiccai-ip-marketing」，内含能力卡：
1. 个人品牌七种武器自检
2. 事故素材挖掘（反对标）
3. 消费者分层洞察（3000 / 30000 / 大中产）
4. 十把镰刀 · 消费心理设计（含防御视角）
5. 盈利游戏设计（被分配者 → 设计者）
6. 好名字 / 名号工程
7. 重复与复利（日拱一卒 + 利他 + 露脸）
8. 低线城市熟人经济打法
