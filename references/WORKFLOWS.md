# 实操工作流

本文件是基于资料提炼的**本技能改造**，不是作者原文。用适合当前任务的模块，不必按顺序执行全部模块。方法出处及纠偏见 [SOURCES](SOURCES.md)。

## 1. IP 定位与诊断

### 从商业问题开始

补齐一张简报即可：

| 需要知道 | 用途 |
|---|---|
| 为谁、什么场景、解决什么问题 | 锁定用户和购买理由；使用产品的人与付钱的人可能不同 |
| 卖什么、怎么交付、客单与购买周期 | 决定内容宽度、信任证据与行动入口 |
| 已有作品、真实经历、独特做法 | 找到主张的事实支撑 |
| 当前数据或具体困扰 | 分清曝光、识别、信任、成交或复购瓶颈 |
| 平台、时间、预算、露脸与隐私偏好 | 选能持续的形式 |

信息不足时先给定位假设和最关键的待补信息，不要求用户先完成冗长问卷。

### 形成定位

用这句话做内部检查，不强迫作为对外文案：

> 我帮助【具体人群】在【具体场景】解决【问题】，用【真实方法/产品】，通过【可展示证据】让人相信。

给出一个推荐方向；只有存在真实取舍时才给备选。说明选它的理由、放弃什么、需要补什么证据。不要靠「专业、靠谱、有温度」三个形容词完成定位。

用七种武器查识别资产，记录「已有 / 待补 / 主动不用」，优先补当前瓶颈对应的一至两项：

| 原框架 | 可执行资产 | 不适用时的替代 |
|---|---|---|
| 脸 | 稳定出镜方式、可辨识画面 | 手部示范、作品过程、固定图文版式；不劝用户违反隐私偏好 |
| 声音 | 自然语气、固定讲解方式 | 字幕/文字表达；合成音需适配信任与适用规则，不冒用他人声音 |
| 名号 | 易读易搜、关联行业的称呼 | 保留已有知名名称，只调整简介和栏目 |
| 主张点 | 对真实问题的明确取舍 | 以做法而非极端判断体现差异 |
| 孤独 | 独立判断与可持续节奏 | 不要求切断家人朋友关系 |
| 同情点 | 自愿公开的局限、错误与修正 | 常见工作难题、服务过程，不必曝光创伤 |
| 重复 | 一贯的主张和识别线索 | 更换论据与场景，监测疲劳与理解偏差 |

### 最小交付

一句话定位 + 简介草案 + 一个核心主张 + 对应证据 + 两至三个可持续栏目 + 下一条内容。用户只要诊断时，交付优先改的动作，不强行写全案。

## 2. 选题与口播

### 素材加工

先读取 T3 的相关条目。以用户真实资料建立素材卡：

`场景 → 当时想要什么 → 障碍/误判 → 做了什么 → 可证实的结果 → 对观众的帮助 → 公开边界`

素材可来自客户常问的问题、作品迭代、采购选择、失败复盘和普通日常；「事故」理解为有代价的变化，不要求灾难、丑闻或自曝隐私。

没有真实经历时，写方法讲解、产品演示，或明确标注的假设情境。不能为让稿子好看而编「我曾经服务过某客户」。

### 选题判断

分别查看人群相关性、冲突是否真实、证据是否足够、是否强化主张、能否连接业务、是否拍得出来。优先做证据足、与瓶颈相关的题；不按未经验证的「爆款评分」排序。

批量选题建议用表格：

`选题/标题｜用户问题｜开头切入｜核心判断｜证据或待补素材｜对应栏目｜行动入口`

角度可以变化：误区拆解、选择对比、真实复盘、过程展示、常见问题、工具示范。不要把同一句观点换词算成多个题。

### 成稿结构

可选骨架：**具体场景或反差 → 明确判断 → 例子/演示 → 可操作的方法 → 自然收束**。按内容调整，不让每条都用「你是不是」「三个秘密」开头。

- 开头兑现正文能回答的问题；尖锐在取舍，不在人身攻击。
- 一条主线讲透，短句口语，删除不推进信息的自夸与铺垫。
- 没有事实支撑的效果改成机制解释或待验证假设。
- 时长按用户要求控制，以试读校正；不把固定字数当成所有人的语速。
- 默认先给可直接读的正文，再给必要的画面、证据占位或创作说明。
- 根据任务设置一个合理行动：记住方法、查看作品、咨询具体服务等，不强迫每条都导流。

**示例（假设的维修账号，不是真实案例）：**

> 水龙头又漏了，先别急着买新的。漏在接口，和关紧以后还滴水，查的地方不一样。先关好供水，再看漏点。这条我用台上的旧件演示，怎么把两种情况分开。拿不准型号，就先拍清楚接口，别凭外观买配件。

此例以过程展示建立信任，不需要虚构「帮客户省了几千块」。实操内容涉及安全时补上对应专业条件。

## 3. 命名、广告语与品牌表达

### 先锁住表达任务

明确品类、目标人群、真实优势、价格/购买场景、使用位置（头像、门头、包装、短视频开头）。从产品事实和消费者已有语言出发。价格/档次/文化只是可试的表达角度，不是高低端公式。

### 命名

可以从品类、卖点、体验好处、熟悉意象找方向；APP/服务型名称可强调功能，不把书中的「APP 名」硬译成「年轻化」。

候选附：读法、含义、行业关联、容易误听/误写之处、扩品类限制。数量按用户需要，不默认产一百个。

先用读一遍能否复述、看名字能否猜用途来筛；商标、重名、域名和平台名需实际检索，没查就标「未检索」，不能写「可注册」。

### 广告语

从同一真实卖点试不同角度：场景解决、用户宣言、具体利益、明确取舍。每句配一个可用证据和使用位置，推荐最符合当前任务的一句。

验收：

- 普通用户能否说出卖什么、解决什么？
- 换成任何竞品都成立吗？若是，补具体方法或特征。
- 是否易读、易复述，画面或演示能否支撑？
- 「熟悉又陌生」是否来自新的表达联系，而非编造事实？
- 「封杀品类」仅是作者对差异化的修辞，不能保证竞品不可使用某句话。

视觉符号与广告语表达同一个主张。比如主张「看得见的制作过程」，画面就应展示过程证据，不只贴一个华丽标识。

### 信任证据

建立 `主张｜作品/演示/资质/评价｜来源｜可公开范围｜缺口` 清单。作品与过程优先于无法证实的名人关系；证据缺失时安排一次可公开的样品演示，不伪造客户背书。书中的六类背书不是每个品牌必须集齐的认证体系。

## 4. 借势与传播

借势不只等于追热点：已有认知、季节场景、地方习惯、品类问题、真实合作资源都可成为连接点。

### 选择一个值得借的势

1. 用户已经认识它吗？没有认知基础就未必节省解释成本。
2. 它与自己的产品或主张有真实联系吗？说不出联系就不硬蹭。
3. 热度是否仍在、是否有制作窗口？实时热点要核验；无法核验时只交条件式草案。
4. 观众记住的是热点还是品牌？给自己的作品、方法或产品一个必要角色。
5. 所需素材、人物与合作是否可用？公开可见不等于获得使用或背书授权。
6. 借来的人群有承接去处吗？只有围观却没有相关需求时，先小试。

输出简短策划卡：

`所借认知/事件及核验时间｜用户关联｜品牌独特连接｜核心创意｜内容/参与机制｜发布资源与窗口｜行动入口｜观察指标｜停止或调整条件`

预算不足时选一个小场景，集中做一个可被展示和复述的动作。争议可来自真实取舍；不制造假事故、假差评、假粉丝冲突。对事实错误及时纠正，对合理批评回应问题，不以黑粉数量作成功指标。

## 5. 转化与商业承接

先画最短链路：**内容 → 识别 → 信任证据 → 行动入口 → 合适的产品/服务 → 交付与复购**。用户只要内容时保持任务范围，不额外推销复杂漏斗。

| 可观察现象 | 先验证什么 | 可尝试动作 |
|---|---|---|
| 有曝光，用户说不清你做什么 | 品类与主张是否可复述 | 固定栏目和简介，补一条讲服务场景的内容 |
| 有关注，没有有效咨询 | 人群是否匹配、证据/入口是否缺失 | 展示作品过程，明确适合谁及咨询所需信息 |
| 咨询多，成交少 | 需求、预算、决策人、交付和报价是否匹配 | 记录流失理由，改善产品说明、分阶段方案；不立即降价 |
| 成交有，复购差 | 产品体验、履约、后续需求 | 改交付和售后；不把产品问题交给内容救火 |
| 突然爆量，业务没变 | 新受众是否在服务范围内 | 看合格线索，不把播放峰值当营收增长 |

报价基于范围、成本、价值、替代方案和交付风险，付款方式适配行业及双方条件。没有成本/毛利数据时提供计算框架，不给伪精确收入预测。

示例指标（本技能改造，按业务选）：

- 合格咨询：同时满足服务范围、明确需求及约定资格条件的咨询；先写清定义。
- 合格咨询率 = 同期合格咨询数 / 同期咨询总数。
- 成交率 = 同一可追踪咨询批次的成交数 / 该批次合格咨询数；长周期业务注明观察窗口。
- 获客成本 = 对应周期可归属获客投入 / 对应新增付费客户数；交代是否计入内容工时。
- 复购率明确「有复购机会的客户群」和周期，不把一次性服务机械考核为零复购。

数据为零时不计算无意义比率；无归因数据时不声称某条视频导致收入变化。

## 6. 全案与复盘

全案包含：当前瓶颈及依据、定位与证据、识别资产、内容样稿、必要的借势、产品承接、可执行节奏与复盘方法。只保留与任务有关的模块。

起步可用两周作为**可调整的试验窗口**，不作为起号成功期限：

- 先确认主张、整理真实证据，记录现有基线。
- 依产能发布一组相近主题内容；比较开头时尽量保持主题、时长、行动入口等条件相近。
- 记录制作成本、观众复述、目标用户反馈、咨询和实际成交，区分平台后台定义。
- 到期决定保留、改写或停止哪条假设。平台分发并非随机实验，小样本结果只作为方向信号。

复盘要能回答：卡点发生在哪里？有哪些证据？还有什么其他解释？下一轮只改哪项？如何判断继续？

**示例（假设的本地家政账号）：** 有播放但无预约，不立即断言选题差。先查观看地域、服务区域是否写清、预约入口是否有效；再看是否展示服务范围、价格条件和过程证据。如果流量来自外地，优先试本地场景；如果本地用户已在问价，优先改善承接。此例是诊断逻辑，不是效果承诺。
